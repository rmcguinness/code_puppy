# Git Workflow & Atomic Checkpoints

1. **Atomic Commits**
   - Keep commits focused on a single change.
   - Commit as soon as tests pass and code compiles cleanly.

2. **Conventional Commit Formats**
   - `feat: [description]` for new capabilities
   - `fix: [description]` for bug fixes
   - `refactor: [description]` for structural improvements without behavioral change
   - `test: [description]` for adding or updating test cases
   - `chore: [description]` for dependency updates or build configurations
   - `checkpoint: [description]` for intermediate development checkpoints
